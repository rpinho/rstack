## 2026-11-18 — GPT-6.2 routing and Google removal (proposal)

GPT-6.2 Sol and GPT-6.2 Astra are available in the local Codex model catalog and official OpenAI documentation. Standard short-context prices per million tokens are $2 input / $0.10 cached input / $10 output for 6.2 Sol, and $8 / $0.40 / $40 for 6.2 Astra. This section updates the earlier “next week” release note. Sources: [OpenAI pricing](https://developers.openai.com/api/docs/pricing), [6.2 Sol](https://developers.openai.com/api/docs/models/gpt-6.2-sol), [6.2 Astra](https://developers.openai.com/api/docs/models/gpt-6.2-astra).

The October 28 task files were recovered and rerun through the installed `codex exec -m MODEL` wrapper with `RSTACK_LANE=harness`, default effort and identical primary-run flags. October used an older CLI/OpenRouter for agentic work and direct API calls for the interpreter, so its figures are historical context. Every completed primary task used one CLI user turn. Interpreter repeat ranges were $0.026985–0.029965 for 6.1 and $0.027460–0.031440 for 6.2. Both models passed all 85 interpreter cases and all six visible agentic tests, while each failed the same one of sixteen original hidden agentic tests (`test_discount_rounding_half_up`, 0.075 versus 0.08). October's archived Sol runs also fail that test; the earlier blanket pass description is inaccurate.

Two sessions had started the same job. Combined calls were capped at eight task invocations: six completed primary runs, one completed auxiliary 6.2 agentic run ($0.042382, with apps/plugins disabled), and one interrupted 6.1 agentic run with unknown final usage. The auxiliary run is retained separately because its CLI flags differ. The full planned repeat-pair cost spread cannot be calculated. The primary task mean is 8.8% higher for 6.2, but this small incomplete comparison does not establish a general cost disadvantage. Source: `route62-1118/COSTS.json` and `REPORT.md`.

Routing proposal: retain `CODEX_MODEL=gpt-6.1-sol` and the existing Sol slots. The rule was to upgrade Sol only if 6.2 was no worse within measured run-to-run spread; these data do not establish that condition. No Sol upgrade is proposed.

Replace the Astra slot in review, judge and ideation with `gpt-6.2-astra`, retaining the Anthropic first choices. Reuse November 17 evidence without new Astra calls: the two inherited review batches were caught by 6.2 Astra in 2/2 cases, versus Sol 1/2 and GPT-6 Astra 0/2; the always-BLOCKED control also catches 2/2. Latest v3.1 calibration has five overall winners, including 6.2 Astra and Sol, so no unique superiority follows. For bounded ideation, 6.2 Astra completed 0/3 calls within 480 seconds versus 3/3 for both older models; the requested Astra routing preference carries that limitation. Sources: November 17 `REPORT.md`, `ROLE_PROPOSAL.md`, `TASK_RESULTS.md`, and the committed `LEADERBOARD.md`.
